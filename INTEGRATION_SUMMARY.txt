================================================================================
ARCHITECTURE IMPACT
================================================================================

HOOK LIBRARY INJECTION:
  CloneEngine → NativeLibHandler → Extract from assets → Inject into clone
  → Clone's HookApplication loads libs → Native hooks active

SOCKS PROXY:
  ProxyManager → Extract microsocks → Start process → Route traffic
  → Cleanup on exit

ZSTD COMPRESSION:
  DataArchiveManager → ZstdOutputStream → Write custom format
  → ~30-50% better than ZIP
